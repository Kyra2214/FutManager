# Lote P1 1101–1110 — timeout

O domínio 02 possui o registro `roadmap_p1_timeouts` no GameState SQLite. O contrato fixa timeout positivo de 30.000 ms para `career_gateway`, com dez ações P1, JSON determinístico, leitura read-only, auditoria e índice SQL.

A mutação permanece protegida pelo serviço SQL autorizado. A auditoria do gateway confirmou dez itens e fonte `SQL_GAMESTATE`. Evidências: `engine/core/p1_timeout_contract.py`, `engine/manager/career.py`, `scripts/career_gateway.py` e `tests/test_p1_timeout_contract.py`.
