# Lote P1 1181–1190 — Convite

O contrato de convite do domínio 03 foi implementado no GameState SQLite com registro dos dez itens, payload JSON validado, hash SHA-256, upsert idempotente, leitura read-only, índice por carreira/convidado/status, auditoria e proteção de mutações por `AUTHORIZED_SQL_SERVICE`. O `ManagerService` inicializa o registro e o `career_gateway.py` expõe contratos, estado, validação, persistência, proteção e auditoria.
