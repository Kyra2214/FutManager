# Arquitetura híbrida de dados

A documentação canônica do fluxo híbrido está em [`docs/fluxo_hibrido_dados.md`](fluxo_hibrido_dados.md).

Este arquivo permanece como referência compatível para links anteriores. O contrato atual é: APK sem banco ou assets pesados, manifesto remoto versionado, download inicial validado por SHA-256, armazenamento privado no Android e funcionamento offline após a preparação.
