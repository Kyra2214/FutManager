# Documentação do FutManager

## Contrato vigente

A leitura recomendada começa pelo [README principal](../README.md), segue para o [fluxo híbrido de dados](fluxo_hibrido_dados.md) e termina no [guia de operação segura](README_operacao_segura.md). Esses três documentos descrevem o funcionamento atual: APK enxuto, manifesto remoto, download inicial, validação, armazenamento privado e operação offline.

A [política de execução do roadmap](roadmap_execution_policy.md) define os critérios de integridade, testes, transações e gates. O [procedimento de recuperação](procedimento_recuperacao_checkpoint.md) explica como separar checkpoint de código, pacote remoto e save do usuário.

## Documentos de domínio

Os demais arquivos Markdown documentam regras esportivas, contratos, competições, economia, treinamento, scouting, UI, segurança e decisões de implementação. Eles continuam válidos como especificações de domínio, mas qualquer instrução sobre instalação ou distribuição deve seguir o fluxo híbrido descrito nos documentos acima.

## Relatórios históricos

Arquivos com nomes de auditoria, benchmark, manifesto de marco ou evidência preservam resultados de execuções anteriores. Alguns contêm caminhos locais como `/home/ubuntu/brasfoot_engine`; esses valores são evidências históricas e não devem ser usados para configurar o APK atual.
