# Lote P1 1071–1080 — versionamento do gateway

O ciclo de versionamento do domínio 02 foi persistido em `roadmap_p1_versions` no GameState SQLite. A versão `career_gateway` usa o valor semântico `1.0.0`, possui dez ações do ciclo P1, JSON determinístico, estado consolidado, índice de consulta e auditoria de mutações.

A validação aceita somente versão semântica, domínio 02, nome de versão conhecido, ação registrada e fonte `SQL_GAMESTATE`. A leitura é read-only. O executor SQL autorizado é o único ator permitido para mutações; tentativas do frontend são registradas e recusadas pelo catálogo de erros do motor.

As evidências do lote estão em `brasfoot_engine/engine/core/p1_version_contract.py`, `brasfoot_engine/engine/manager/career.py`, `brasfoot_engine/scripts/career_gateway.py` e `brasfoot_engine/tests/test_p1_version_contract.py`.
