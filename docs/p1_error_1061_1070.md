# Lote P1 1061–1070 — erros do gateway

O ciclo de erros do domínio 02 foi consolidado em `roadmap_p1_errors`, no mesmo GameState SQLite inicializado pelo `ManagerService`. Cada item possui código de erro catalogado, ação canônica, contrato JSON determinístico, versão de esquema, estado consolidado e fonte `SQL_GAMESTATE`.

O gateway expõe leitura, validação e auditoria. Tentativas de mutação do frontend são registradas em `roadmap_p1_error_audit` e recusadas com `P0_MUTATION_AUTHORIZATION_REQUIRED`; somente o serviço SQL autorizado pode prosseguir. A auditoria é read-only e verifica dez IDs, códigos conhecidos, ações válidas, JSON íntegro, índices e fonte de verdade.
